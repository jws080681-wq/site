# 수공종합설비 · 수공디자인

소비자가 누수 증상, 방수 공법과 비용, 견적 확인사항, 실제 시공 사례를 쉽게 찾도록 정리한 홈페이지입니다.

## 사이트 운영

GitHub Pages는 `main` 브랜치의 루트 폴더를 게시합니다. 별도의 설치나 빌드 없이 파일을 수정하고 커밋하면 기존 Pages 배포가 실행됩니다.

- `index.html`: 안내 문구, 공법별 참고 단가, 연락처, 블로그 링크
- `styles.css`: PC·모바일 디자인
- `app.js`: 선택적인 앵커 처리; 주요 기능은 JavaScript 없이도 작동
- `assets/`: 제공된 블로그의 실제 현장 사진
- `SOURCES.md`: 안내와 사진의 출처
- `.nojekyll`: 빌드 없는 정적 파일 게시

전화번호 변경 시 표시 번호와 모든 `tel:`·`sms:` 링크를 함께 수정하세요. 전화·문자 버튼은 기기의 앱을 열며, 별도의 개인정보 수집·전송 폼은 없습니다.

단가는 2026-09-28 저장 HTML에 있는 참고 금액이며 확정 견적이 아닙니다. 현재 가격을 확인한 뒤 적용 조건과 기준일을 함께 수정하세요. 출장 지역·영업시간·보증기간은 자료에서 확인되지 않아 임의로 약속하지 않았습니다.

## 로컬 확인

이 폴더에서 `python -m http.server 4173`을 실행한 뒤 `http://localhost:4173`에 접속합니다. 하위 경로에서도 이미지와 스타일이 작동하도록 상대 경로를 사용합니다.
